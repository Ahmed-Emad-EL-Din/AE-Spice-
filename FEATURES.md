# AE Spice - Feature Specification & Capabilities

Welcome to **AE Spice**, a premium, high-performance, interactive mobile analog circuit simulator. Designed for absolute focus, speed, and precision, AE Spice replaces traditional engineering overhead with a streamlined workspace experience.

---

## 🚀 Key Innovation Features

### 1. Immersive Launch Sequence
*   **Fully-Blocked Synchronized Bootstage**: Guarantees a zero-flash, bleed-free entrance. No main application workspaces or interface layouts are instantiated or visible in the background until the splash screen completes its execution lifecycle.
*   **Polished Adaptive Entrances**: Clean Material 3 visual introduction transitions that gracefully scale and present the primary brand.

### 2. Stylized Tech-Modern Branding Logo
*   **Precision Typography Overlays**: Custom vector tracking that renders the brand name `"AE Spice"` in a bold, stylized monospace/sans-serif technology font.
*   **Dynamic Golden-Yellow Focus Accent**: The lowercase `"i"` features a dynamically computed, high-contrast shining golden-yellow dot (`#FACC15`) aligned perfectly with the logo's geometric structure. This is accomplished using a system font mapping mechanism over a dotless `"ı"` base character, followed by a local Canvas measurement offset overlay.

### 3. Full-Screen Interactive Circuit Schematic Canvas
*   **100% Immersive Viewport**: Shifts away from cramped, divided split layouts to provide an uninhibited workspace for designing complex netlists.
*   **Touch-Input Optimization**: Fluid gesture-based panning, pinch-to-zoom, and conflict-free single-finger drag actions.

### 4. Search-First Dynamic "Components" Panel
*   **High-Density Direct Insertion**: Replaces bulky instructional wizards with an optimized, rapid-filter catalog.
*   **Instant Component Search**: Type-ahead filtering allows engineers to quickly locate resistors, capacitors, inductors, diodes, transistors, or voltage sources and drop them directly into the canvas.

### 5. Floating Real-Time "Waveform" Terminal
*   **Compact Toggle Action**: Dismissable wave plotter trigger removes clutter and maximizes active screen area.
*   **Dynamic Edge Snapping**: Allows panels and waveform triggers to float freely or slide and lock seamlessly onto viewport edges with a 20px magnetic proximity snapping threshold.
*   **Full Spatial Persistence**: Real-time recording of window dimensions and coordinates via Jetpack local preferences, preserving workspace customization reliably across app restarts.
